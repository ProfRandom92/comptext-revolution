📄 AutoResearch Framework (Karpathy)
Overview
AutoResearch is a framework for autonomous machine learning research. It enables: • Continuous hyperparameter optimization • Automated experiment discovery • Real-time result aggregation • Reproducible research workflows Our application: Autonomous compression level discovery for CompText.
Key Concepts
1. Phase-based Exploration: Divide optimization into logical phases 2. Adaptive Sampling: Focus compute on promising variants 3. Metric Tracking: Real-time performance monitoring 4. Discovery Reporting: Document novel findings Applied to: Discovering optimal compression levels (1-9) and dictionary sizes.
📄 Token Compression Techniques
DSL Approach
Domain-Specific Language compression achieves 85-90% token reduction by: • Abbreviated namespaces (@db → @d) • Parameter shortening (query → q) • Symbol encoding (true → 1) Ideal for: Queries, APIs, configuration files
Vowel Reduction
Level 4-5 compression removes internal vowels: • "configuration" → "cfgrtn" • Maintains readability for LLMs • 54-55% reduction without semantic loss Key insight: LLMs understand consonant skeletons better than humans.

📄 NLP & Compression Theory
Why Compression Works
LLMs are trained on vast language variations including: • Abbreviations (u → you) • Acronyms (CEO, API) • Shorthand (omw → on my way) Transformer architecture naturally handles compressed representations because: • Attention learns frequency patterns • Embeddings encode semantic relationships • Context disambiguates abbreviations
Practical Implications
• Extreme compression (Level 5) is LLM-transparent • Hybrid approach combines best of both worlds • Dictionary optimization is ROI-positive • Reversible compression enables human review
